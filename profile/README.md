# OpenWOP

**Run AI agents as workflows you can watch, pause for a person's approval, and rewind, on any host that implements the protocol.**

OpenWOP (Workflow Orchestration Protocol) is an open-source protocol for multi-agent workflow orchestration. The spec is CC BY 4.0 and the code is Apache 2.0.
